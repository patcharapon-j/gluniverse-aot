## Ground rules

- **Source of truth.** YAML first, then the chapter, then the render check (ADR-0012). Every new table is a YAML block rendered between `BEGIN RENDERED` and `END RENDERED` markers.
- **Shared files.** Two packages that edit the same file at the same time use HANDOFF's lock rule: an empty lock file `docs/rules/.lock-<basename>` that the waiting agent loops on (for example `docs/rules/.lock-render.py`, `docs/rules/.lock-OPEN-QUESTIONS.md`). The packages below own disjoint chapters and YAML folders, so a lock is needed only for `tools/render/render.py` (WP-G1 and WP-G4) and for the register if a drafter logs a reading.
- **No simulator run.** Batch 9 changes no closed number (9-17). Nobody runs `tools/sim/run.py`. WP-G5 runs one smoke load at the end to prove the engine still reads `data/`.
- **The term.** The ladder is **Circumstances**, and the word "difficulty" appears in no rule text, YAML key, or glossary line except in the words "the GM may adjust difficulty" quoted from the owner in a design note. Severity and Attack Dice keep "difficulty" under Avoid.
- **The line.** Every Rulings paragraph and every reworded `gm:` field reads the same way: what the GM rules in that scope, then what the GM applies as written, closing with a pointer to Chapter 1, section 1.1, item 6 (9-11). The GM rules before the dice, never after them.
- **Citations.** Every "ADR-0003, item n" in a package's files becomes "ADR-0024, limit n" (9-18). Design notes cite the batch item (decision batch 9, 9-n) and the OQ, as the chapters do today.
- **Playtest tag.** A rule Phase 2 replaces (the Requisition list preface's "the GM may add", the Foe direction rule, Waypoint scenes) carries the packet's "Playtest rule" tag, never an explanation.
- **Checks after every package:** `uv run --with pyyaml python tools/render/render.py check`; the YAML load command in HANDOFF; for WP-G3, `tools/probes/chapter-06/render.py check` and `run6.py check`. A package is done when its checks pass, it has no `PROVISIONAL` marker it did not mean to leave, and a grep of its files for "No rulings", "No dice by judgment", "never adds or removes dice", and "ADR-0003" finds nothing.
