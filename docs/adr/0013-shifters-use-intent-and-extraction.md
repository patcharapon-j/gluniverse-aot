# Shifters act from Intent Tables and are extracted, not killed

Shifters are run as Focus Titans with four differences: an Intent Table replaces the Attention Ladder, Hardening can raise Toughness or block Nape strikes, reaching Nape Depth starts an Extraction clock instead of killing, and each regeneration spends Shifter Stamina until the human must emerge. The Colossal Titan is the exception, run as a scene-wide disaster rather than something to fight. An Intent Table keeps an intelligent enemy within ADR-0024, limit 8, since the GM never has to pick a Shifter's target by judgment.

## Amended

After decision batch 9 (2026-09-16, GM judgment; ADR-0024, 9-18): the reason "the GM never has to pick a Shifter's target by judgment" no longer binds, since GM judgment is valid. The Intent Table stands, because a Shifter's fight is Titan-measured content and its tactics must be readable and tuned like a Behavior Table (ADR-0014). Revisit when Shifters are drafted. The record's citation of ADR-0003 reads ADR-0024, limit 8, as 9-18 gives (the GM judgment review round 3, 2026-09-16).
