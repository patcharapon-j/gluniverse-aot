# Shifters are not playable in the core game

Shifters are always GM-controlled in the core game, even though Titan World allows playable shifters. A playable Shifter becomes the main character and breaks the core premise that fragile humans survive Titans only through teamwork and setup. A playable-Shifter module may come later, but the core rules are not designed around it.

Hostile Shifters are run under ADR-0013. Allied Shifters, unavoidable in a Close campaign from Trost in 850 onward, are GM-controlled assets inside an Operation Frame: they advance its objective clock, the Squad protects them, and a Loses Control Table can turn them into a hazard.
