## Ground rules

- **Source of truth.** YAML first, then the chapter, then the render check (ADR-0012). Every new table is a YAML block rendered between `BEGIN RENDERED` and `END RENDERED` markers.
- **Shared files.** Two packages that edit the same file at the same time use HANDOFF's lock rule: an empty lock file `docs/rules/.lock-<file>` that the waiting agent loops on. The parallel groups below are chosen so that this is rare; the table under each package lists its files.
- **No simulator runs during YAML edits.** The full rerun (WP-S2) starts only when every YAML package is done and the lock files are gone. Nobody runs `tools/sim/run.py` before then.
- **Playtest tag.** Every rule Phase 2 replaces (Chapter 7 whole, the seven-day Downtime, the Requisition list, unmeasured Talents, the prosthetic row) carries the packet's "Playtest rule" tag, never an explanation. Burn now has sources, so the Burn names carry no tag.
- **Checks after every package:** `uv run --with pyyaml python tools/render/render.py check`; the YAML load command in HANDOFF; for packages that touch Chapter 6 or `data/titans/`, `tools/probes/chapter-06/render.py check` and `run6.py check`. A package is done when its checks pass and its files carry no `PROVISIONAL` marker it did not mean to leave.
- **Design notes** cite the batch item (decision batch 7, 7-n; decision batch 8, 8-n) and the OQ, as the chapters do today.
- **Severity and Attack Dice.** After WP-R, "Severity" means the number a Titan's or a Foe's roll scored, and "Attack Dice" the pool an entry prints. A drafter who finds "Severity" used for a pool anywhere after WP-R fixes it in place, whichever package owns the file, under the lock.
