# Milestone 2 (Core) review, 2026-09-16

Scope: `git diff 7456405..HEAD -- foundry`, against the ADR-0025 checklist. Only blocking and major findings are listed.

Checks: `pnpm install --frozen-lockfile`, `pnpm build` (packs built), `pnpm test` (8 files, 109 tests pass) and `pnpm typecheck` (clean) all pass.

## Blocking

**B1. A player can use the GM proxy to change actors they do not own.** `src/dice/proxy.ts:48`, `:51`, `:54`, `:68-88`
- Any user who owns a soldier can rewrite the flags of any card (`:48`). That includes `cover.actor`, `targets` and `ops`.
- `recentCardFor` then allows any `update`, `create-item` or `delete-item` on any actor the card names, and `perform` applies the request's data unfiltered. For example, a player sets themselves as Cover on another player's roll. They can then send `{ownership: {<me>: 3}}` or `system.*` changes for that roller. On an attack card, a targeted player can create or delete the Titan's items (`:54` has no type check).
- **Fix:** on the GM side, accept only changes that match an op recorded on the card (same actor, item and path, value equal to `numValue`, `op.to` or `op.from`). Card rewrites must differ from the stored card only in `cover`, `reactions` and op `state`.

## Major

**M1. A new WebGL context leaks when a sheet closes mid-animation.** `src/motion/widgets.ts:417-423`, `:150-152`, `:499-503`
- `destroy()` does not cancel the widget's anime.js tweens. Their `onComplete` calls `schedule(this)` after the last widget has been disposed.
- `flush()` then calls `ensureShared()` before it checks `isConnected`, so it creates a new renderer that nothing ever disposes.
- **Fix:** keep the tween handles and cancel them in `destroy()`, have `schedule()` ignore destroyed widgets, and return early from `flush()` when `widgets.size === 0`.

**M2. The Reduced motion path still moves the blades.** `src/motion/widgets.ts:406`, `:489-491`
- Reduced keeps the `fall` tween, which drives the blades' position and rotation as well as their opacity. OS `prefers-reduced-motion` users therefore see the blades slide and spin.
- **Fix:** at Reduced, use `fall` for opacity only (skip the position and rotation terms), or tween a separate `fade` value.

## Limitation (not counted)

The Titan sheet's view leaves out hidden values (`titan-view.ts`). However, Foundry syncs every Actor's full data to every client, so the Behavior Table and Next Behavior are still readable from the browser console. If that matters, store them in GM-only storage.

Rules math spot-checked against `data/` with nothing wrong found: pool building, Push, Cover, success counting, wear, Stress Response, derived values, and Titan regeneration and strikes.

## Resolution

- **B1** fixed in `f292c51`. The GM side now runs every request through `src/dice/proxy-guard.ts`. A card rewrite may differ from the stored card only in Cover, Reactions, a call card's answer and op state. Each of those is checked: a Cover must be the user's own soldier and agreed on that soldier's flag, a Reaction must match its dodge card, and only the roller's owner changes op state. Actor and item changes must match an op on the card, or the pending Cover cost of a Push. They must come from the roller's owner, use a path a card op writes, and carry the value from `numValue`, `op.to` or `op.from`. Changes to another actor are limited to the Cover cost, need the comrade's agreement, and a replay is refused. Item create and delete must match a recorded gear op on the same actor. The GM writes the card summary itself. `test/proxy-guard.test.ts` covers the three abuses and the Push, Cover, Undo, Redo and Dodge flows.
- **M1** fixed in `6fb0bcd`. `destroy()` cancels the widget's tweens, `schedule()` ignores destroyed widgets, and `flush()` returns before `ensureShared()` when no widget is left. `test/widgets.test.ts` covers a late tween callback and an already queued frame.
- **M2** fixed in `16f5bcb`. At Reduced, `fall` drives only the blades' opacity. Covered in `test/widgets.test.ts`.

Checks: `pnpm build`, `pnpm test` (10 files, 126 tests), `pnpm typecheck` and `svelte-check` pass. Browser check on the isolated 14.365 server (port 30055, scratch data, licence removed after), with a GM and two players:
- Player2 Covered Player1's roll through the GM. Player1's Push put 1 Stress on the covering soldier, and Undo and Redo moved it back and forth.
- Player1 undid the GM's Push on their soldier.
- Player1's Dodge and its Push were recorded on the Titan attack card.
- Direct proxy queries from Player2 were refused: an ownership change, a `system.*` write, a card rewrite that added an op, a Titan item create, and a delete of another player's gear.
- Three rounds of closing a sheet during the blade ruin animation each left no live WebGL context and opened no new one.
- No console errors.
