# Milestone 4 review: Engagement tracker

Scope: `git diff 4a23c82..HEAD -- foundry`. Checks: `pnpm test` (15 files, 241 tests) and `pnpm typecheck` pass.

## Blocking

**B1. The GM applies player-written cards without checking them.** `src/tracker/results.ts:49-75`
- `onCard` runs on every created or updated chat card. It does not check who wrote the card. It also does not re-check the entry's requirements (`napeStrikeBlock`, `bodyPartStrikeBlock`, Break Attention, Break Free).
- A player can post or edit their own message with a forged card, such as a Nape strike of all 6s from any Position. The active GM then kills the Titan. A forged `attack` or `foe-attack` card applies Grabs, injuries and death to other players' soldiers. `recordDodge` and `markOdm` also trust the card.
- **Fix:** before applying, require the author to own `card.actor` (and a GM author for attack and foe cards). Re-run the block checks on the GM. React to updates only when the proxy guard would allow the change.

**B2. A Titan's death moves the turn to the wrong card.** `src/tracker/engine.ts:733-738`
- The loop sets initiative to null on every card of the dying Titan except the current one, including cards already played. `turns` gets shorter, but core v14 keeps `combat.turn` as an index.
- The current turn jumps ahead, and `_manageTurnEvents` runs: `cardEnd` counts a Grab turn, and `cardStart` can roll the other Titan's attack.
- **Fix:** clear only cards with `turnNumber > combat.turn`, or commit with the `combatTurn` option.

## Major

**M1. A round-end step can be applied twice.** `src/tracker/engine.ts:762-772`, `src/tracker/state.svelte.ts:112-117`, `src/tracker/view.ts:350`
- While `runEnd` is running, the HUD still shows "Next check", and `applyCheck` has no lock. A click, or a second GM, applies the same step again: Regeneration +2, or duplicate Gas Rolls.
- **Fix:** add a per-combat busy lock around apply, undo and `runEnd`, and hide the actions while it is held.

**M2. A Squadmate on a dead player character's Wing is skipped.** `src/tracker/engine.ts:206-216`, `:260`; `src/rules/engagement/cards.ts:25`
- Keep Wings ignores `reassign`, so the Squadmate stays kind `wing`. It is dealt a card, but `deal` only writes cards for kind `soldier`, so its card is lost and it never acts.
- **Fix:** refuse `keep-wings` while `reassign` is not empty, or drop Wings whose player character is dead or has left.

**M3. A player's departure does not reopen Wings.** `src/tracker/engine.ts:639`
- `wingEvent` runs only on a GM client, and there is no guarded `left` request.
- **Fix:** add a guarded `left` request, or have the active GM watch `positions.left`.

**M4. A soldier freed by the Titan's death loses their corpse Position.** `src/tracker/engine.ts:728`
- By `grab.yaml` release.titan_dead and `positions.yaml` corpse, their last Position is on-body, so they should hold in-reach relative to the corpse.
- **Fix:** set `positions[label] = 'in-reach'`.

**M5. A Titan that enters never works out its Attention.** `src/tracker/engine.ts:657-699`, `src/tracker/results.ts:236`
- `background-titans.yaml` (full_clock) says an entering Titan evaluates its Attention Ladder. Here the holder stays empty until the Titan's first card, so the would-be holder can make a Nape strike.
- **Fix:** run `evaluateLadder` in `enterTitan`, using this round's cards only mid-round.

**M6. Undo shifts numbers that changed after the step.** `src/rules/engagement/round.ts:149`
- The plan says a value changed later is kept, with a warning. The code instead moves it back by the op's delta. The Regeneration clock can end up with wrong values.
- **Fix:** return `undefined` for numbers too.

## Note

The engine's Titan death step (`titanDies`) has no test. Nothing covers the removal of its cards, the corpse Positions or the freed soldier.

## Resolution

Checks after the fixes: `pnpm test` (17 files, 257 tests), `pnpm typecheck`, `pnpm build` and `svelte-check` pass.

- **B1** `943567c`: `src/rules/engagement/card-trust.ts`. The GM ignores a card whose author does not own its roller, and Titan or Foe attack cards not written by a GM. It checks strike, Break Attention and Break Free requirements again once any earlier result is taken back. A player's edit is acted on only when it is a real Push, a Cover, or an op state change, compared with the GM's last accepted copy. A result's digest is kept on the engagement, so a result a player changed is never undone or applied again. `recordDodge` also checks that the attack is a GM card and that the dodger is one of its targets. Tests: `test/card-trust.test.ts`.
- **B2** `1eb678a`: `planTitanDeath` clears only the dead Titan's cards after the current turn. This commit also adds the missing `titanDies` test (card removal, corpse Positions, the freed soldier's steam and fall).
- **M1** `caba57b`: a per-engagement lock (`src/tracker/busy.ts`) covers run, apply, skip and undo. Only the active GM runs them, and the HUD and board hide those actions while the lock is held.
- **M2** `61aa1da`: `roundBlock` refuses Keep Wings while `reassign` is not empty.
- **M3** `2a5a3b4`: a guarded `left` request lets the GM record a player's departure and reopen Wings.
- **M4** `4d91c23`: the freed soldier holds In Reach relative to the corpse.
- **M5** `5e7a8ae`: `enterTitan` works out the Attention holder with `enteringAttention`. It uses this round's cards only during play.
- **M6** `af95348`: `revertValue` keeps any value changed after the step, numbers included.
