## Dice and Successes

- Roll when an action's Catalog entry is rolled, when a rule or table result calls for a roll, or when the GM calls one. No roll where failure changes nothing, or where the soldier has the time, tools, and training; a task that cannot be done is never rolled. C 28
- Results stand: once the dice are rolled the GM never overrides, has rolled again, or ignores a die or table result, and never changes the roll's entry, its Circumstances, or its stakes; a roll changes only by a Push or a rule naming the change. C 46
- The GM rules before the dice, never after: whether to roll, what the roll uses, the Circumstances, what failure costs, all said before anyone rolls. C 28-29, 46; `ADR-0024` preamble
- Rolled in the open: Titan Dice, a Foe's Attack Dice and Guard, the hazard and Night tables, the setup table, every roll on a table. Hidden: the Next Behavior, rolled once and standing, and the passive roll. C 46, 48
- D6, xD6 (added; tables and adding rolls only, never a pool), D66 (tens then ones, 11 to 66). C 55
- Pool holds base, Gear, Stress Dice; distinct colours; Bonus Dice are base dice. C 56
- Every 6 is a success on any kind. C 57; DP 15, 21, 29
- Titan Dice: in no pool, succeed on 5 or 6, never Push, never take Bonus Dice, Help, Gear Dice, Stress Dice, or Circumstances. C 57, 363
- Die kinds, Push behaviour, and 1s (DiceKey): base 1 nothing, rolled again unless 6; Gear rolled again on 2 to 5, a 1 locked and wearing 1 point per Pushed roll; Stress rolled again unless 6, 1 is a Stress Response. DP 13-32
- Attribute roll = rule names an attribute; rolled actions, Reactions, Death Rolls (Strength), called rolls, and called attribute rolls. Only these use a pool, count successes, can be Pushed. C 62
- Other rolls (Gas Roll, table) roll stated dice, add nothing, take no Circumstances, cannot be Pushed. C 64
- Pool = attribute + one Talent + Bonus Dice + Gear Dice + Stress Dice, less penalties, in order: name the roll and its Circumstances, attribute, Talent, Bonus, penalties, Gear, Stress. C 68-81; DP 36-124
- Step limits (Fig. 1): attribute 2 to 5, 6 on Specialty key attribute; Talent 0 to 3, one Talent; Bonus 0 to 4; penalties never below 1 base die, never Gear or Stress Dice; Gear 1 to 3 from one item, 0 worn; Stress = current Stress, no maximum. DP 37-124
- Name the roll: one Catalog entry unless a rule, or the GM for a called roll, calls an attribute directly; entry names attribute and gear; dodge, block, Death Roll are not actions but Talents can name them; the GM names the Circumstances at this step, before Bonus Dice. C 70
- Talent: at most one dice-adding Talent, must name the entry; entry condition applies (Horsemanship: mounted, horse's Gear Dice); rule-bending Talents apply on trigger and stack. C 76
- Penalties: from a named rule (e.g. a Wounds & Fear table) or a minus step of Circumstances; they add up; all after the cap. C 78; DP 79-95
- Gear: worn to 0 adds none; choose one before rolling if several; entry allows none, no Gear Dice. C 80
- Stress Dice in every attribute roll except listed exceptions. C 81
- Rolls called by attribute (by a rule or by the GM): attribute alone, no Talent dice; Bonus Dice from covering sources, Gear only from an item the calling rule names, Stress Dice. A called roll on an attribute alone names no gear item, so no Gear Dice; a helping item counts toward Circumstances instead. C 74; DP 40, 97
- Acts no rule covers: outside a fight the Chapter 2 steps stay the default order and the list of values is an index, not a gate, so an act matching none is ruled on; in a Titan Engagement or a Skirmish the steps are not used and the act is an improvised act, or a called roll. C 72
- Death Roll: no Stress Dice, never a Stress Response, cannot be Helped. C 81
- A roll leaves out pool parts only if its rule says so and it is listed; a procedure may forbid Help or Push without a listing (Graduation Exam Trials). C 81
- Exceptions table: Death Roll (Strength; leaves out Stress Dice; no Help; no Push; Talent dice allowed); performance roll (higher performance attribute; leaves out Talent, Bonus, Gear, Stress; no Help; no Push); passive roll (the attribute of the entry the GM rolls for; leaves out nothing; no Help; no Push). DP 263-307
- Final when Pushing stops or cannot; each 6 one success. C 131
- Needs 1 success unless the rule names another number, and every such number is a quantity in the world or a tuned value (Nape Depth; a Foe group's Parley value). A called roll always needs 1. The GM never raises or lowers a need, and Circumstances never change it. A Reaction needs none, it cancels. A failed roll does only what its rule states, or on a called roll what was staked; a silent rule means no effect. C 132
- Successes beyond need do only what the rule lists; some rules total across rolls (Toughness). C 133
- Each success used once; exception: Reaction cancels against several attacks from same Titan or Foe that round. C 134
- Example (Liesel, Emil): Nape strike is Strength with Blade Set gear; Clean Cut names Nape strike. `data/character/action-catalog.yaml` 117-122; `data/character/talents.yaml` 74-80

## Circumstances

- Every attribute roll has Circumstances: one step of a seven-step ladder the GM names for the situation; Standard if none is named. C 100; CIR 15-45, 52-53
- Ladder rows (CoreTable `circumstances`): Effortless +3 Bonus Dice, Routine +2, Easy +1, Standard no change, Hard a 1-die penalty, Harsh a 2-die penalty, Desperate a 3-die penalty. CIR 16-44
- One step per roll: everything about the moment is one judgment; a step named for a lasting condition is the step of every roll it touches while it lasts; a further condition is weighed into one step for that roll; steps never add, and the lasting step still applies to rolls the further condition does not touch. C 101; CIR 46-53, 159-165
- Named with the stakes, before Bonus Dice are declared, so the player can answer a minus step with Help. C 101, 114; CIR 55-59
- Plus steps are one Bonus Dice source, counting toward the cap of 4 with every other source; the roller chooses under the cap; a plus step left out spends nothing. C 102; CIR 77-80; BD 54-74
- Minus steps go through the pool's penalty step: after the cap, base dice only, adding up with every penalty carried, never below 1 base die, never Gear or Stress Dice; a soldier always rolls at least 1 base die. C 103; CIR 81-84
- Which rolls: every attribute roll a soldier or a Squadmate makes, including a called roll, an action, a Reaction, and every roll a rule calls for. A group's roll takes one step on its roller's pool. C 105; CIR 85-90
- Never: a roll that is not an attribute roll, the Death Roll, the performance roll, the Graduation Exam's Trials, Titan Dice, a Foe's Attack Dice and Guard. C 105; CIR 94-124; DP 271, 281
- Needs never change: a Nape strike against Nape Depth 4 at Hard still needs 4, out of one die fewer. C 107; CIR 134
- Fixed once named: a Talent, a Push, or a Cover never changes the step, and nothing changes it once the dice are rolled. C 108; CIR 74-76, 135
- A Reaction takes the step in force when the attacker's card comes up; no step is named, raised, or lowered for it until that card ends; a condition arising during the card counts from the next card; a dodge cancelling against a later card keeps its step. C 109, 333; CIR 60-66
- Too easy is not rolled, it happens; impossible is not rolled and the GM says so first; anything possible is at worst Desperate. C 106; CIR 126-130
- Routine and Effortless mostly serve a soldier carrying penalties. C 106; CIR 131-133
- In a Titan Engagement: Standard is the assumption because the Anchor Rating, Positions, Openings, a grounded Titan, Call It, the Attention restriction, and carried penalties already price the fight; another step only for something no rule prices (rain, smoke, full dark, ice, a gale); it reaches every attribute roll a soldier makes in the fight, the dodge and the Nape strike included. C 111; CIR 137-158
- A condition that would slow or blind a Titan reaches the table only through the soldiers' dice: a Titan mired to the knee makes the dodge against it Easy, named before its card comes up, and the Titan loses no Attack Dice. CIR 166-170
- Never in a fight: the Titan's dice and Titan Dice roll, its cards and who they resolve against, the Next Behavior once rolled, the Attention Ladder, the Reaction procedure and Grab countdown, Nape Depth, Toughness, Regeneration, Heave, the Openings an entry creates, Steam, the Falling Titan, Corpse Heat, the harm tables, the retreat clock, the end tests. CIR 171-182
- A Leg Hazard's or Night row's own roll takes the step in force when the hazard is rolled, and none is named for the danger the row describes. CIR 67-73

## When the GM Calls a Roll

- A called roll: an act no rule covers, its outcome in doubt, failure costing something; called sparingly. C 28; DP 126-130
- No roll where failure changes nothing or the soldier is unpressed with time, tools, and training; the GM says before anyone rolls that a thing cannot be done. C 28; DP 148-152
- The GM names first, in order: the entry (the closest Catalog entry marked as rolled when called, or an attribute alone), the Circumstances (Standard if none), the stakes (what failure costs, and where it is not obvious what success gives). C 29-32, 37-39; DP 153-165
- The player may change their approach or withdraw before the dice are rolled. C 41; DP 166
- A called roll needs 1 success, can be Pushed, Covered, and Helped. C 58; DP 167-169
- Once rolled, the entry, the Circumstances, and the stakes never change, and the result stands. C 46; DP 178-181
- A roll a rule calls for takes only its Circumstances from the GM; its entry, needs, Help, and failure are its rule's. C 41; DP 182-184; CIR 56-59
- One act with one outcome for several soldiers is one called roll by one soldier the players choose, with Help from the others; Stress, damage, or a fall falls on the roller, a lost item is the roller's, a lost unit is the Squad's, time or position falls on the situation; an act each makes for themselves is each soldier's own roll. C 28; DP 131-136
- Failure costs what was staked and nothing else: either it does not happen, or it happens at one cost, or it does not happen and the cost falls anyway. One cost per failed roll. A failure should move the story on. C 43, 52; DP 185-188
- The menu (CoreTable `called-roll-costs`): it does not happen (the default, always available); 1 Stress; a fall, low or high as the GM names from the height, low if none is named, never extreme, and in a fight a fall in full landing as the fall rule gives; damage 1 to 3 of a named Injury Type, never 4 or more; one carried item lost or 1 unit of one kind of Squad Supply, never wear; time or position, and in a fight nothing the fight tracks. C 44-48; DP 189-218
- The GM states the soldier's current Health with any stakes naming damage or a fall. C 50; DP 219
- Never staked: a Critical Injury dealt directly, an Injury Location, a row, or a time limit; a Death Roll, a Scar, or Grief; a Fear Roll; Stress relief, a Health box, healing time, or a care window; a Titan's roll, a Foe's roll, or a table result. C 52; DP 220-226
- Success gives: the act, information, a better position, an object that is not a gear item, or Squad Supply found within Chapter 4's caps. Never a gear item, Stress relief, a Health box or healing, a Commendation, a Research Point, or a Faction Standing change. C 52; DP 227-234
- In a fight a called roll is the last resort: only for an act no entry of kind action the soldier could take there could model, that changes nothing the fight tracks (no value the rules name, Position, Engaged or Apart, Attention, Opening, card, clock, or Foe value); the model entry is tried first; it spends the action, is made on the soldier's turn, never gives an effect an entry has, and never stands in for a Reaction; Help on it is the fight's Help at no cost the GM names; its fall lands as the fall rule gives. C 28, 302; DP 137-147
- What a ruling never touches (C 49): the Push (no ruling forbids or forces one), Covering, Help's effect and cap; Bonus Dice sources, the cap of 4, penalties, and what a roll needs, with Circumstances the one source a ruling names; the fixed rolls and their tables (Fear Roll, Stress Response roll, Gas Roll, Death Roll, performance roll, fall roll, infirmary roll); the Critical Injury, Stress Response, Scar, and Grief tables, Down, Death Rolls, healing, care windows; Stress relief; gear wear, Standard Issue, Funding, the Ledger, one Requisition per Downtime; Behavior Tables, the Attention Ladder, Attack Dice and Titan Dice, the Reaction procedure, that only a Nape strike kills a Titan, the size of Openings, Steam, the Falling Titan, Corpse Heat, the Grab countdown, Regeneration, the retreat clock, the end tests; a standard Titan's numbers and the Read-gating of hidden values; the Leg roll except its Circumstances, the hazard and Night tables with their rolls and amounts, "always advance", rations, the Straggler's random victim; Squadmates, whom the players direct; and every die and table result once rolled.
- Passive roll: a Spot or Size Up the GM makes out of sight, outside a Titan Engagement and a Skirmish, for something the soldier does not know is there. The pool is the soldier's as it stands (attribute, the Talent naming the entry, Gear Dice if the entry allows, Stress Dice) with the Circumstances the GM names to themselves; a plus step adds its dice and no other Bonus Dice source applies; no Help, no Cover, no Push; a Stress Die showing 1 does nothing; the soldier learns the result only through what they notice; it is not a called roll, has no stakes, and failing it means only that the soldier does not notice; a soldier who says they are looking rolls Spot in the open as a called roll. C 48; DP 284-307
- Trying again: in a Titan Engagement or a Skirmish, on a later turn, a called roll included, spending that turn's action and nothing else. Outside, a rule that says never is final; otherwise only when something has changed (a new approach, a better tool, another soldier, or time spent), at a cost of time or position named before the new roll, falling when the soldier tries again whatever the result, and not the new roll's stakes; one attempt per soldier at a given obstacle per changed situation. C 47; DP 235-245
- Example (Mila and the sergeant): Persuade, Hard, Empathy 3, Help 1, penalty 1 after the cap, 3 base dice and 1 Stress Die; first roll 5, 2, 4 and a Stress Die 3, no success; Push to 6, 1, 3 and Stress Dice 2, 5, one success. C 113-127

## Pushing Your Luck

- Push trades Stress (and wear) for a second chance; allowed after failure or success. C 138
- Cannot Push: Stress Die 1 on the roll or after an earlier Push; rule forbids (Death Roll, first two Trials); a passive roll; not an attribute roll; already Pushed the allowed number (once unless a Talent); a held state or result forbids (Down). C 142-149; `data/harm/down.yaml` 23
- No ruling forbids or forces a Push; extra Pushes follow the same procedure; a Stress Die 1 after any Push rules out more. C 49, 151
- Push steps (Fig. 3): roll, Stress Die 1 means Stress Response and no Push; decide, one comrade may Cover before any die is rolled again; gain 1 Stress and add 1 Stress Die, or the Covering soldier gains it and no die is added; roll again every die not showing 6 but a Gear Die showing 1, plus the new die, 6s stay; Stress Die 1 now means a Stress Response. C 157-162; SC 21-27
- Bonus Dice rolled again unless 6; Gear Die 1 stays locked. C 160; DP 24
- One Stress Response per roll, however many 1s or Pushes. C 164
- Gas: Pushed roll with ODM Gear makes that round's Gas Roll three dice; three however many; not if the Gas Roll was already made; Pushed ODM dodge counts; Pushed mounted horse dodge wears the horse and does not by itself make it three. C 174
- Gear Die 1: if Pushed, each 1 when final wears its item by 1; these are first-roll 1s; unPushed roll no wear; ODM Gear at 0 Jams. C 169; DP 25
- Base die 1 nothing; Stress Die 1 a Stress Response, except on a passive roll. C 168, 170
- Finishing order: count; resolve Stress Response on the Wounds & Fear table at post-Push Stress unless the rule names another resolution (Graduation Exam), which still has the Response and still cannot be Pushed after; apply a change to roll or action now; changed count holds for later uses incl. Reaction cancelling; apply the effect, or on a failed called roll the staked cost; apply wear if Pushed. C 178-183
- Who can Cover: not the Pusher, not Down; player character (Squadmates never Cover); in a Titan Engagement same Position or one step; outside, qualifies to Help that roll under the calling rule, or the Skirmish's Help rule, or, on a called roll outside a Skirmish, as the GM rules; a calling rule that allows no Help allows no Cover; no held state or result forbids. C 191-196; SC 29-47; `CONTEXT.md` 195-201
- When: after Push declared, before any die rolled again; one Cover per Push; Pusher can refuse; Pusher chooses among offers; a Push rolling no die again (all base and Stress Dice show 6) cannot be Covered. C 197
- What it takes: Coverer gains 1 Stress; not an action; spends neither move nor action; outside spends nothing, needs only the eligibility Help has on that roll. C 198; SC 29-47
- Effect: Pusher gains no Stress, adds no die; Stress Dice still rolled again; Stress Die 1 still gives the Pusher a Stress Response; Gear 1s still wear the Pusher's gear; Coverer makes no roll, no Stress Response. C 199-200
- Example (Greta): any wear ruins a Blade Set. `data/gear/items.yaml` 93

## Stress

- Stress is fear and adrenaline; Stress Dice = current Stress except exceptions (Death Roll); 6 succeeds, 1 sets off a Stress Response; more capable and more likely to break. C 206
- No maximum; starts at minimum; losses stop at minimum. C 206, 208; SC 11-17
- Carries over between Titan Engagements, Expeditions, sessions; changes only through listed triggers; the GM never changes it without one, and a ruling changes it only as the stakes of a called roll. C 210, 221
- Minimum = number of Scars, 0 with none; never below; rises immediately on a new Scar. C 214-216; SC 12-15
- Scars mean at least that many Stress Dice; a Scar raises Resolve by 1; Resolve counts against Stress Response and Fear Roll results; five Scars must retire. C 217
- Table rows: Push +1 (uncovered); Cover +1; ruling +1 (fail a called roll staked on Stress, once per failed roll however many Pushes, never on a success); named gains incl. hunger and Fear contagion (within one Position step, Stress not a roll, no Fear Roll); Engagement ends -1 (any reason incl. retreat; everyone, PCs and Squadmates, who held a Position at any point); Nape kill -1 (everyone holding a Position at the kill); named losses; camp relief -1 (camp roll succeeds, no hunger; everyone on the Expedition); Skirmish ends -1 (everyone who took part); Downtime -2 (Recover, Visit Haven, Squadmate relief); Graduation Exam ends, lose all (every Cadet who took it). C 227; SC 20-121
- Both at once: a Nape kill ending the Engagement triggers both in full. C 230; SC 71-88
- Holding a Position is the test; end relief includes soldiers who left, retreat still gets it however many rounds; kill relief for holders at the moment, not only the striker; departed soldiers get nothing from the kill. C 232-235
- Rally clears a Stress Response, does not lower Stress. C 238
- Downtime: Haven lowers Stress and Grief via Downtime Actions such as Visit Haven. C 240
- Stress Response only from a Stress Die 1, at most one per roll, never on a roll with no Stress Dice, never on a passive roll; table and Resolve in Wounds & Fear. C 244
- Fear Roll never from dice; a closed list of horrifying events in Wounds & Fear, one row of which the GM reads: outside a Titan Engagement, an event at least as horrifying as a listed trigger. Inside one, only the list. C 245

## Bonus Dice and Help

- Bonus Dice are extra base dice from Help, Openings, a plus step of Circumstances, and listed situations. C 249
- Listed sources only; Circumstances is the one source a ruling names; declare before rolling, none after, not even before a Push; cap 4 from all sources; over the cap the roller picks; unused sources unspent (Openings stay, an unused helper keeps their action, a plus step spends nothing); base dice (6 succeeds, Push rolls again unless 6, 1 nothing); penalties after the cap, a minus step among them. C 251-256; BD 9-12
- Table rows: Help 1 per helper up to 3 (not the Death Roll, the performance roll, a passive roll, or a roll whose rule forbids Help; spends the action in a Titan Engagement or a Skirmish, what the calling rule states on a rule's roll outside both, and nothing on a called roll outside both unless the GM names a cost of time or position); Circumstances 1 at Easy, 2 at Routine, 3 at Effortless, one step per roll, spends nothing; Opening 1 per Opening spent (Nape strike; not your own Opening; spends the Opening); grounded Titan 2 (Nape strike; Broken leg); Reading from Distant 2 (Read; hold Distant to the Focus Titan); Call It 2 (dodge; comrade's Read Called the behavior; reader's own dodge gains nothing); medical supplies 1 (Treat Injury in a care window, never in a Titan Engagement or aftermath; 1 medical unit held; spends it); Ambush 2 (soldier's Fight or Shoot in a Skirmish; Squad has the ambush and Foe has not acted). BD 14-159
- Help adds 1 die; up to 3 comrades; comrade = any other soldier, PC or Squadmate. C 260
- Help requirements: not roller, not Down; PC or Squadmate whose action list has Help; roll allows Help (exceptions table names the Death Roll and the passive roll, plus the roll's own rule); declared before; in a Titan Engagement unspent action this round (turn or action spent in advance begins spent) and same Position or one step; outside, the calling rule's requirement, or in a Skirmish a comrade taking part who is not Down, Engaged or Apart, or on a called roll outside both the GM's ruling that they are present and able to help concretely; no held state or result forbids. C 266-274; BD 14-53
- Effect: 1 Bonus Die per helper, counts toward the cap; the helper does not roll, cannot Push it, no Stress, no Stress Response. C 278-279
- Spends: the helper's action in a Titan Engagement; can Help outside own turn or during a comrade's Reaction while the action is unspent; a later own turn has only its move. C 283
- Outside a Titan Engagement: on a roll a rule calls for, only where that rule allows, and it states who and what it spends, silence meaning no Help and no Cover; on a called roll, up to 3 comrades present and able as the GM rules, spending nothing unless the GM names a cost of time or position before the dice, which falls when Help is declared whatever the result and is not the roll's stakes, and a comrade who could Help may Cover; in a Skirmish, a comrade taking part who is not Down, each spending their action at no cost the GM names, and Help on a called roll in a Titan Engagement is that fight's Help. The Effect limits still apply. C 287-292

## Turns, Actions, and Reactions

- Titan Engagement runs in rounds; Fighting Titans sets the order (initiative cards, Tempo, Wings). C 296
- Each round every PC takes one turn of one move and one action; baseline move is one Position step; Overloaded makes ODM moves spend the action too. C 300
- Action = Help, one Catalog entry not marked as not an action, an improvised act, or a called roll for an act no entry of kind action could model that changes nothing the fight tracks. C 301
- Improvised acts: in a Titan Engagement or a Skirmish, the GM names the one existing entry whose effect the act imitates, its model entry, before the pool is built, and that ruling stands; an act that is not an entry taken as written is improvised even when a value it would change matches an entry; the model entry is of kind action and one the soldier could take in that fight, never a Reaction, a roll, a fixed roll, or an option; the act spends the action and is rolled with the model entry's attribute, gear, Talents, and needs, taking Circumstances as any roll does; an act modelled on an unrolled entry is not rolled; on a success it produces only the model entry's effect at that entry's size and carries its restrictions; it never kills a Titan, never changes Nape Depth, Toughness, Attack Dice, or a card, never cancels or delays a card, never creates more Openings than the model could, never gives an effect no entry has; only a Nape strike taken as written kills. C 302
- Move and action once per round, not saved, refresh each round except those spent in advance. C 303
- Declining: may decline either or both; unspent parts stay until round end but only for Help and Reactions (a Reaction needs both); a lone held move does nothing after the card passes; held parts lost at round end. C 304
- Spending a turn: earliest turn from this round with move and action both unspent; if this round's is partly spent, the next such turn, skipping turns spent in advance. C 305
- Spent in advance: begins its round spent; a result spending only the action in advance leaves the move; rules read that state; turn spent means no Help, no Reaction with that turn, nothing to decline; action spent means no Help, no Reaction with that turn, hold only the move. C 306
- Forbidding: a state or result forbids Push, Help, Cover, or Reaction only by naming it; other requirements still apply; Down forbids all four; Grabbed forbids Help, Cover, Reaction. C 307; `data/harm/down.yaml` 23; `data/engagement/grab.yaml` 16
- Not actions: Reactions, Pushing, Covering, declaring Bonus Dice sources, spending Openings on the roll they join. C 308
- Reaction: dodge or block when a Titan or Foe acts against you, outside your turn; against a Titan, when a card resolves a behavior against you and its Attack Dice are rolled. C 312
- Full-pool attribute roll for its own entry; can be Helped and Pushed. C 313
- Spends one whole turn (move and action). C 314
- Can react whether or not you acted, if no earlier Reaction against that Titan or Foe this round and nothing forbids it; none against a 0-success attack, Reaction kept. C 315-319
- Which turn: this round's if both unspent; else the next turn in full and this round's remainder usable on your card if not yet come; if the next is partly spent, the one after, and so on; a Grab gives back a later turn spent by the dodge against that card or the earlier cancelling dodge; turns spent in advance still happen and count for turn-counting rules, begin with no move or action, no Help or holding. C 320-325
- Engagement ends: turns and actions spent in advance cancelled; nothing owed; the next Engagement starts unspent. C 326
- Severity = the attack's successes; Net Successes = what remains after cancelling. C 332, 335; `CONTEXT.md` 203-205, 348-350
- Attack and Reaction (Fig. 4): the attacker rolls and finishes first incl. an allowed Push (a soldier attacking a person may Push; a Titan and a Foe never), Severity announced, the roll then fixed; each target decides knowing the Severity and rolls for its own entry, with Help and Bonus Dice declared before and at the step fixed when the card came up, Pushing last, changing only by its own Push and Finishing step 2; a target who already reacted to that Titan or Foe this round rolls nothing new and cancels with that Reaction; each Reaction success cancels one attack success; leftovers are Net Successes, 1+ lands and the effect reads them, 0 whiffs; no Reaction or a forbidden one cancels nothing; a 0-success attack whiffs against all and no Reaction is made. C 332-336
- Each target cancels against the same roll with their own Reaction; one attack can land on one and whiff on another. C 338
- Against a Titan: only a dodge, no block; Agility, Gear Dice from ODM Gear or the horse while mounted, one item; the Titan's attack is the behavior's Attack Dice as Titan Dice; one Reaction per Titan per round; choose to dodge when a card resolves against you with 1+ successes, declining leaves all net and keeps a later dodge; dodge successes (after Finishing step 2) cancel against that card and separately against later cards that round; each card on its own Net Successes; later cancelling does not use successes up; a Critical Injury adds 1 per Net Success beyond the first; a Grab, a knock loose, and a Stress gain take no rider. C 340-347
- Against a person: in a Skirmish, a dodge or a block as the attack allows; one Reaction covers every attack that Foe makes against you that round, separately; a landed attack deals weapon damage plus 1 per Net Success beyond the first; Skirmishes gives which attacks, Guard, and the ambush. C 349
- Block only where the attack allows it: a Foe's Fight attack in a Skirmish; no Titan allows it. C 351
- A Squadmate's attribute rolls take Circumstances like any soldier's. C 359
- Closing example (Mila, Oskar): all numbers and steps; the dodge's step is Standard. C 369-386
